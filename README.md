## 🎨 কাস্টমাইজেশন

আপনার তথ্য অনুযায়ী নিম্নলিখিত অংশ সম্পাদনা করুন:

### নাম এবং বর্ণনা সম্পাদনা
`index.html` এর হোম সেকশন খুলুন এবং সম্পাদনা করুন:
```html
<h1>আপনার নাম</h1>
<p class="subtitle">আপনার পেশা</p>
<p class="description">আপনার বর্ণনা</p>
```

### রঙ পরিবর্তন করুন
`style.css` এ গ্রেডিয়েন্ট রঙ পরিবর্তন করুন:
```css
background: linear-gradient(135deg, #আপনার_রঙ1 0%, #আপনার_রঙ2 100%);
```

### প্রজেক্ট যোগ করুন
নতুন প্রজেক্ট কার্ড যোগ করুন:
```html
<div class="project-card">
    <h3>প্রজেক্ট নাম</h3>
    <p>প্রজেক্ট বর্ণনা</p>
    <a href="#" class="project-link">আরও জানুন</a>
</div>
```

### সোশ্যাল লিংক যোগ করুন
ফুটারে আপনার সোশ্যাল মিডিয়া লিংক যোগ করুন:
```html
<a href="আপনার_লিংক">আপনার_প্ল্যাটফর্ম</a>
```
